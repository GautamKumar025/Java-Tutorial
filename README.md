# ☕ Complete Java Tutorial: Basic to Advanced

A structured, hands-on repository containing Java programs, concept implementations, and problem-solving exercises—ranging from absolute beginner fundamentals to advanced Java topics.

## 📚 Syllabus & Topics Covered

### 🟢 1. Java Basics
* Variables, Data Types, and Type Casting
* Operators and Expressions
* Control Flow Statements (`if-else`, `switch`, loops)
* User Input (`Scanner` & `BufferedReader`)
* Escape Sequences and String Formatting

### 🟡 2. Object-Oriented Programming (OOP)
* Classes, Objects, and Constructors
* Method Overloading & Method Overriding
* Inheritance (`single`, `multilevel`, `hierarchical`)
* Polymorphism (Compile-time & Runtime)
* Abstraction (`abstract` classes & `interfaces`)
* Encapsulation and Access Modifiers (`public`, `private`, `protected`, `default`)
* `this`, `super`, `static`, and `final` keywords

### 🟠 3. Core Java & Intermediate Concepts
* Arrays (1D, 2D, and Jagged Arrays)
* Strings, `StringBuilder`, and `StringBuffer`
* Exception Handling (`try`, `catch`, `finally`, `throw`, `throws`, Custom Exceptions)
* Packages and Wrapper Classes
* File I/O Operations (`File`, `FileReader`, `FileWriter`)

### 🔴 4. Advanced Java & Collections
* **Collections Framework:** `List` (`ArrayList`, `LinkedList`), `Set` (`HashSet`, `TreeSet`), `Map` (`HashMap`, `TreeMap`), `Queue`
* **Multithreading & Concurrency:** `Thread` class, `Runnable` interface, Synchronization
* **Java 8+ Features:** Lambda Expressions, Functional Interfaces, Stream API, `Optional` class
* Generics and Annotations
